System Administration Completed 2024

About This Project

Managed Linux servers (Ubuntu, CentOS, Red Hat) with shell scripting for automation. This project also involved configuring essential network services on Windows Server, including setting up DNS for name resolution and DHCP for dynamic IP address allocation within the network.

Linux Administration
Installed and maintained various Linux distributions, performing package management and user administration.
Shell Scripting
Wrote BASH shell scripts to automate routine tasks such as system backups and health checks.
DNS Configuration
Configured and managed DNS zones and records on Windows Server for reliable name resolution.
DHCP Management
Set up a DHCP server to automatically assign and manage IP addresses for client machines.
