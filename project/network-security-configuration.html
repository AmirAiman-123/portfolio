About This Project

Implemented VPN and firewall rules for a simulated enterprise network. This assignment focused on securing network infrastructure by applying best practices for IAM to control access, and configuring firewalls to filter traffic and prevent unauthorized entry.

Key Objectives & What I Did

Site-to-Site VPN
Configured a site-to-site VPN to securely connect two virtual networks.
Firewall Rules
Wrote and applied firewall rules (Security Groups/NACLs) to allow legitimate traffic while blocking potential threats.
Security Hardening
Followed security hardening guides to reduce the attack surface of virtual servers.
Network Monitoring
Monitored network logs to identify and analyze suspicious activity.
