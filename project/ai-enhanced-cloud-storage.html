About This Project

AuraDrive is an intelligent cloud storage platform I built with a Python/Flask backend and a React frontend, designed for role-based access in an educational setting. The application features a full hierarchical file system, multi-drive scopes (Personal, Community), and a "Desktop-Class" UI with previews and multi-select. The core feature is DriveAi, a Groq Llama 3-powered assistant that executes natural language commands for file management, search, and content summarization. For a live demo, please feel free to contact me. I will turn on the server, as this project is self-hosted on my personal hardware and domain named www.tvetikmbsmartdrive.com. This project is still ongoing. If there are any questions or advice, feel free to contact me anytime.

Core Features

AI-Powered File Management (DriveAi)
Use natural language commands (e.g., "find all pdfs from last week") to manage files with Groq Llama 3.
Hierarchical File System
Complete folder and file structure with full CRUD capabilities.
Multi-Drive Scopes
Separate "Personal" drives for private files and a "Community" drive for shared resources.
Role-Based Access Control
Admin, teacher, and student roles with different permissions for data security and privacy.
Desktop-Class UI
Modern interface built with React, featuring drag-and-drop, file previews, and responsive design.
