Cloud Deployment Practice

Multi-Cloud Completed 2024

About This Project

Configured and deployed virtual servers on AWS and Azure. This project involved setting up secure and scalable cloud infrastructure from scratch, including configuring Identity and Access Management (IAM) roles for proper permissions, utilizing S3 storage for static assets, and establishing a Virtual Private Cloud (VPC) for network isolation and security.

Project Gallery

Key Objectives & What I Did

EC2 & VM Deployment
Launched and configured EC2 instances on AWS and Virtual Machines on Azure.
IAM Security
Created custom IAM policies and roles to enforce the principle of least privilege.
S3 Storage
Set up S3 buckets with appropriate permissions for public and private data.
VPC Architecture
Designed and implemented a VPC with public and private subnets for a tiered architecture.

Technologies Used

AWS Azure IAM VPC S3 EC2
